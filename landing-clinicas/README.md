# Marc.I.A. para Clínicas — página da oferta

Página estática, independente do site Next.js da Ichthus (não é importada pelo app).

## Publicar em clinicas.ichthusmkt.com.br (Vercel)

1. Vercel → Add New → Project → importar `ichthus-site`.
2. Root Directory: `landing-clinicas`. Framework Preset: **Other**. Sem build command.
3. Domains → adicionar `clinicas.ichthusmkt.com.br`.
4. No DNS de ichthusmkt.com.br: registro `CNAME clinicas → cname.vercel-dns.com`.

Links de WhatsApp: +55 19 99805-6642. Parâmetros `utm_source`/`utm_campaign` da URL são anexados à mensagem.
